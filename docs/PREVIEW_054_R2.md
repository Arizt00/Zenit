# Zénit 0.5.4 · Preview R2

Mi actividad incorpora cabecera con la foto del perfil desvanecida, identidad
centrada, tipografía más legible, recuentos reales y una tarjeta para continuar
el último archivo. Pestañas/búsqueda forman una barra compacta; el historial
conserva teclado, menús y apertura real.

Inicio sigue la referencia nocturna a pantalla completa, con paisaje y esfera
Blender/Babylon. Las barras se ocultan sin impedir el scroll. La apertura espera
la API nativa antes de Monaco y recibe el tema real antes del primer módulo.
Ventanas auxiliares no sobrescriben la distribución principal. Los accesos
directos usan un lanzador estable para abrir la revisión activa.

Melody caduca consejo/audio al cambiar la revisión del código. Conserva la voz
Qwen de Emma previamente preparada y las integraciones existentes.
