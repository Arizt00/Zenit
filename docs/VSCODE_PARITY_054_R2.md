# Paridad verificada · 0.5.4 R2

R2 añade fiabilidad de apertura y persistencia de distribución. La matriz de
[R1](VSCODE_PARITY_054_R1.md) conserva sus contratos y pendientes: iconos,
configuración global, comandos, editor, marketplace, terminales, Debug,
workspace y Melody. No hay un denominador medido de toda la API; no se asigna
un porcentaje global.

| Contrato R2 | Comprobación |
| --- | --- |
| API nativa antes de Monaco | WebView2, domJSON y módulo AMD Java; seis ciclos normales y seis con puente retrasado 3 s |
| Tema antes del primer módulo | Origen nuevo sin localStorage; tema real del perfil y rechazo de cache ajeno |
| Distribución duradera | Separación nativa excluida; redimensionar una ventana auxiliar no cambia el layout principal |
| Lanzador estable | Manifiesto activo, recuperación numérica y rechazo de rutas externas/backups |
| Historial | Archivo/carpeta reales, búsqueda, teclado, pestañas y menús sin inventar actividad |
| Terminales | Scroll sin barras y regresión de Terminal normal/Forge explícito; transporte ConPTY existente |
| Consejos hablados | La revisión real caduca consejo/audio; no certifica calidad del proveedor |

Product Icon Themes, ámbitos completos de configuración, OAuth integrado,
CustomDocument binario y compatibilidad universal de APIs continúan pendientes.
