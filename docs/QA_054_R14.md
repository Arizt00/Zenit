# R14 verification

Verified on Windows x64, 15 October 2026.

- JavaScript syntax checks and all 114 Node tests passed.
- The full Python suite completed 378 tests, with nine environment-dependent
  or opt-in tests skipped. The focused Hilo, editor-window and real dependency
  suite completed 23 tests, with one live-VM test skipped.
- Seven R14 browser checks passed, with no page errors. They cover unsaved
  buffer handoff, tab and split-pane removal, reopening an external document,
  returning it, two independent external editors, all open-in-window routes,
  external hover controls, fixed rail geometry at 1600/1280/900 pixels, activity
  animations, extension views, neutral compound-field focus, responsive aligned
  dependency panels and packages for an actual active Lantern environment.
- All 12 existing workflow checks passed, including .tern create/save/restore,
  cancellation, editor-group merging, submenu keyboard navigation, collapsed
  corners, settings geometry, streaming Unicode and reader position.
- All nine setup checks passed, including contrast in the three native themes,
  responsive panel alignment, editable previews and reduced motion. A nine-pixel
  profile-step scroll overflow was corrected during this verification.
- Sixteen actual packaged WebView2 checks passed, including the new native
  document handoff/focus/return path with unsaved text. Five frozen-backend
  session checks passed using the bundled Python interpreter, pip and debugpy.

Browser screenshots and JSON reports are under `tests/visual/r14`,
`tests/visual/r14-regression` and `tests/visual/r14-setup`. Native reports and
complete test logs are under `qa-output/r14-*`.

existing environment tests. This iteration does not repeat the opt-in two-boot
live QEMU test recorded for R12. QEMU and a prepared base image remain required;
.tern retains disk data through its accompanying .lumen/tern directory, not RAM.

local Conan library in C/C++, together with language-service refresh. Complete
VS Code API parity and authenticated access to all external applications are
outside this verification.
