## Scope and limitations

VM resource selections and their `.tern` round-trip are tested. R13 does not
repeat the two-boot live Arch/QEMU test recorded in `QA_054_R12.md`; its VM engine
is unchanged. QEMU and a prepared Arch base are required, and saved VM sessions
preserve disk contents rather than guest RAM. Python venvs isolate dependencies,
not operating-system permissions. `.tern` descriptors rely on the accompanying
`.lumen/tern` backing directory.

Connection adapter presence and argument construction do not certify authenticated
sessions with all external applications. No complete VS Code API compatibility,
code signing or public release is implied.
