# Zénit roadmap

The next work follows complete workflows rather than a feature count.

## Available in R5

- Coordinated editing, terminals and native detached windows.
- Melody’s destination, code scope, live edit and selection review.
- Forge’s real execution status, repeat and process stop.
- Search filters, file icon themes, profile/activity and three palettes.
- English presentation, Apache-2.0 and contribution templates.

## Next priorities

1. Complete English localization of advanced legacy panels and backend messages.
2. Extend extension API compatibility with verified examples.
3. Add regex search and reviewed project-wide replacement.
4. Evaluate Melody on real coding tasks separately from fixture tests.
5. Extend shell integration and share Forge execution history between windows.
6. Build and verify current Linux/macOS packages on those platforms.
7. Establish signing and a repeatable stable-release checklist.

Discuss focused proposals in [Discussions](https://github.com/Arizt00/Zenit/discussions).
This roadmap is a direction, not a promised date.
